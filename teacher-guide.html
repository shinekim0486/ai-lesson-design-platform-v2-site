플랫폼 수업설계로 돌아가기 가이드 내려받기

정보 교과 교사용 가이드

AI 수업설계 플랫폼에서 정보 교과 수업안을 만드는 방법입니다. 순차 탐색과 이진 탐색을 비교하는 50분 수업을 예로 들었습니다.

플랫폼에서 수업안 만들기

  1. 학습 목표에 차시 제목과 목표를 입력합니다. 예시 목표는 “같은 자료에서 순차 탐색과 이진 탐색의 비교 횟수를 기록하고, 이진 탐색에 정렬이 필요한 이유를 설명한다”입니다.
  2. 학습 내용에 자료 목록, 탐색할 값, 학생이 기록할 항목을 적습니다. 아래 예시를 사용하거나 학급 수준에 맞게 목록을 바꿉니다.
  3. 교수학습 방법에서 실습을 선택하고 시간에 50분을 입력합니다. 성찰 질문에는 “자료가 정렬되지 않았다면 어떤 탐색을 쓸 수 있나요?”를 넣습니다.
  4. 평가 방법에 아래 평가 기준을 붙여 넣고 마지막 단계의 진행 버튼을 누릅니다. 대시보드에서 저장한 수업설계 건수를 확인합니다.

플랫폼의 AI 초안과 루브릭 생성은 예시 기능입니다. 제안된 문구와 평가 기준은 교사가 수업에 맞게 편집합니다.

50분 수업 예시

준비물은 숫자 카드 8장 또는 종이 활동지입니다. 왼쪽부터 3, 7, 12, 18, 25, 31, 42, 56을 놓고 목표값 31을 찾습니다.

시간교사와 학생 활동
5분두 방법 중 목표값을 더 적은 비교로 찾을 방법을 예상합니다.
15분맨 앞부터 한 칸씩 비교합니다. 확인한 값과 비교 횟수를 기록합니다.
15분정렬된 목록의 가운데를 비교하고 후보 범위를 절반씩 좁힙니다. 가운데 후보가 둘일 때는 왼쪽 값을 선택합니다.
10분목표값을 3으로 바꿔 다시 비교합니다. 처음 실험의 결과가 모든 경우에도 적용되는지 토론합니다.
5분학생 메뉴의 성찰 일지에 예상, 비교 횟수, 결과를 설명하는 근거를 적습니다.

교사용 확인값 목표값 31은 순차 탐색에서 6회, 이진 탐색에서 2회 비교합니다. 목표값 3은 각각 1회와 3회 비교합니다.

평가 기준 예시

  • 우수 두 알고리즘의 확인 순서와 비교 횟수를 정확히 기록하고, 정렬 조건과 목표값에 따른 결과 차이를 설명합니다.
  • 보통 두 알고리즘의 비교 횟수를 기록하고 이진 탐색의 정렬 조건을 설명합니다.
  • 기초 한 알고리즘으로 목표값을 찾고 비교 순서를 기록합니다.
  • 추가 지도 비교할 위치나 다음 후보 범위를 정하는 데 안내가 필요합니다.

다른 정보 교과 주제에 적용하기

  • 데이터 같은 표에서 평균과 중앙값을 비교하고, 극단값 하나를 넣었을 때 결과가 어떻게 바뀌는지 설명합니다.
  • 프로그래밍 점수에 따라 결과를 분류하는 조건문을 작성하고, 기준값 바로 아래와 위를 포함해 경계값을 시험합니다.
  • 인공지능 같은 질문에 조건을 추가하기 전과 후의 응답을 비교하고, 근거 자료로 확인한 내용과 확인이 필요한 내용을 기록합니다.
